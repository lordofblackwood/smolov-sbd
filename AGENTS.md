# Smolov SBD project rules

- Host this PWA on GitHub Pages at https://lordofblackwood.github.io/smolov-sbd/ using the existing `.github/workflows/pages.yml` deployment. The source repository is https://github.com/lordofblackwood/smolov-sbd.
- Sites is only the existing Powerlevel encrypted-history connector at https://powerlevel-sync.micak27.chatgpt.site. Do not register or publish the PWA frontend through Sites. The earlier tracker Sites address is only a legacy data-recovery page.
- The user canceled the November 15 meet. The current frontend uses a next-workout sequence: three full training weeks, seven full recovery days (168 hours from the final Cycle 1 finish), then another three training weeks. No meet deadline, peak or taper in the current sequence; retain legacy results and helpers for data compatibility.
- Calibration retains the actual successful RPE 6–8 single as the explicitly confirmed TM. Confirmed TMs skip unnecessary unstarted calibration tests. Preserve saved calibration dates/targets, original split calibration if already begun, and all active/historical snapshots and outbox records.
- Each training week retains the supplied modified six-workout pairings: 1 deadlift; 2 squat/bench; 3 squat/bench; 4 light deadlift then 5×3 at 85% bench; 5 squat/bench; 6 squat alone. Keep existing percentages/sets/reps and 69/69/33 totals. Preserve original pairings for unstarted sessions in an already-started original-layout legacy week.
- Before each untouched new week after Cycle 1 week 1, ask separately per lift how last week felt: easy +15 lb, good +10, decent +5, OK 0, hard −5. Offsets accumulate per lift across weeks and into Cycle 2. No default response; preview before confirmation. Preserve begun weeks’ own rules and immutable saved target snapshots. No automatic TM estimation or reset between cycles.
- New workouts use stable programSessionId positions and actual America/New_York activity dates. Advance only on finish (complete/partial) or explicit skip; never skip based on dates. Keep schema-v1 backups compatible, including optional weekly reviews, and preserve local records on conflicting imports.
- Use the existing supported Powerlevel contract and authentication. Never submit synthetic/test workouts to live accounts, create duplicate exercise IDs, or reimplement scoring.
- Preserve account-scoped local records and the durable outbox. Hosting-origin changes require explicit backup/import; never assume browser-local records move with deployment.
- Test and build with the Pages base path. `BASE_PATH=/smolov-sbd/ npm run build` and `TEST_BASE_PATH=/smolov-sbd/ npm run e2e` verify the deployed shape. A manually started Vite preview also needs `BASE_PATH=/smolov-sbd/`.
